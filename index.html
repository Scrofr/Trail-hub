Confidentialité

Trail Hub ne collecte aucune donnée. Pas de compte, pas de cookie, pas d'analytics, pas de backend. Tout est stocké dans le localStorage de votre navigateur, sous le préfixe trailhub..

Les seules requêtes réseau sont :

  • Chargement des bibliothèques (Chart.js, Leaflet, JSZip) via CDN
  • Tuiles OpenStreetMap pour la carte
  • API Open-Meteo (météo, altitude)
  • API Nominatim (géocodage)

L'import Strava se fait entièrement dans le navigateur : le fichier .zip ne quitte jamais votre appareil.

À propos

Trail Hub est un outil personnel pour traileurs : minuteur de fractionné, analyse de charge (ACWR), barème running, planification et météo. Aucune inscription, aucun serveur, aucune limite.

Barèmes running inspirés des tables de niveaux usuelles (Fédé, VMA, chronos de référence). Les seuils sont ajustables dans le code (voir BAREME).
